# How to Use Local Notion

## Daily Workflow

1. **Capture** → Drop ideas, articles, or notes into `00_System_of_Record/Forms/Inbox.md`
2. **Process** → Move and refine them into proper folders (Knowledge Base, Projects, Tasks)
3. **Organize** → Use tags, links, and the frontmatter fields from `templates/`
4. **Review** → Weekly review using the dashboard and Dataview queries

## Where Things Go

| Item | Location |
|---|---|
| Daily notes | `05_Personal_Productivity/Notes/` |
| Tasks | `05_Personal_Productivity/Tasks/` |
| Projects | `00_System_of_Record/Projects/` |
| Meeting notes | `00_System_of_Record/Meeting_Notes/` |
| Knowledge / reference | `00_System_of_Record/Knowledge_Base/` |

## Dashboard

Open `dashboard/index.html` in your browser → **Open Vault Folder** → select this folder. You get live stats, task lists, project views, and search — fully offline.

## Weekly Review

Every Sunday:
- Open the dashboard and check open tasks
- Check overdue and upcoming due dates
- Review project progress
- Clean up the Inbox

## Backup

Use the Obsidian Git plugin or manual `git push` regularly.
