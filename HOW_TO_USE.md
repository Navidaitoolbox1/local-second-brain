# How to Use Local Second Brain

## Daily Workflow

1. **Capture** → Drop ideas, articles, or notes into `00_System_of_Record/Forms/Inbox.md`
2. **Process** → Move and refine them into proper folders (Atomic Notes, Projects, Tasks)
3. **Organize** → Use tags and links
4. **Review** → Weekly review using dashboards

## Recommended Daily Notes Location

`05_Personal_Productivity/Notes/Daily/`

## Weekly Review

Every Sunday, review:
- Open Tasks Dashboard
- Check overdue and upcoming tasks
- Review projects progress
- Clean up inbox

## Backup

Use Obsidian Git plugin or manual `git push` regularly.
