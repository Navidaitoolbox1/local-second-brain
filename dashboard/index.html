Welcome

This dashboard turns your Markdown vault into a live workspace. Tasks, projects, notes and meetings, plus a drag and drop Board. It runs entirely in your browser.

New here? Click ▶ Load demo data in the sidebar to see it working right away.

Ready for your own notes? Click 📂 Open Vault Folder and pick this repository folder. Chrome or Edge give the best experience, including saving changes back to your files.

Work right here: click any item to open and edit it, use ＋ New to create one, and drag cards on the Board. Set a PIN in ⚙ Settings to lock the dashboard.

Reading is read only. Files are written only when you save an edit, create an item, or move a Board card, and the browser has write permission.
