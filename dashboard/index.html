🗂️ Local Second Brain Dashboard

A free, local, open-source alternative to Notion. Your files never leave your machine — everything runs in this page.

Welcome 👋

This dashboard turns your Markdown vault into a live workspace — tasks, projects, notes and meetings with stats, search and filters. It runs entirely in your browser.

New here? Click ▶ Load demo data above to see it working instantly with sample content.

Ready to use your own notes? Click 📂 Open Vault Folder and pick this repository folder:

  1. Best in Chrome or Edge (native folder picker).
  2. In Firefox/Safari it falls back to a folder upload dialog — still 100% local.

🔒 100% offline — no network requests, no uploads, no tracking. Reading is read-only; nothing in your vault is ever modified.
