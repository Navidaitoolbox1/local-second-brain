Welcome

This dashboard turns your Markdown vault into a live workspace. Tasks, projects, notes and meetings, plus a drag and drop Board. It runs entirely in your browser.

New here? Click ▶ Load demo data in the sidebar to see it working right away.

Ready for your own notes? Click 📂 Open Vault Folder and pick this repository folder. Chrome or Edge give the best experience, including saving Board changes back to your files.

Want a lock? Open ⚙ Settings and set a PIN.

Reading is read only. A file is written only when you move a card on the Board and the browser has write permission.
