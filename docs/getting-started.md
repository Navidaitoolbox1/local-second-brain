# Getting Started with Local Second Brain

Welcome to your fully local, free Second Brain system.

## Quick Start

1. Clone this repository
2. Run `python setup.py` to create the folder structure
3. Open the root folder in Obsidian
4. Start capturing ideas using the templates

## Recommended Obsidian Plugins
- Dataview
- Tasks
- Obsidian Git (optional)
- Templater (recommended)
