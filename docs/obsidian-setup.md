# Obsidian Setup Guide

## Open the Vault

1. Open Obsidian → **Open folder as vault**
2. Select the repository root folder

## Recommended Settings

- Settings → Files & Links → enable **Detect all file extensions**
- Set your default note location to `00_System_of_Record/Knowledge_Base`
- Set your template folder to `templates/` (Settings → Core plugins → Templates, or Templater)

## Plugins

| Plugin | Why |
|---|---|
| Dataview | Powers the queries in [dataview-mastery.md](dataview-mastery.md) |
| Tasks | Due dates, recurring tasks, task queries |
| Templater | Fills `{{date}}` and other placeholders in `templates/` |
| Obsidian Git | Auto-commit and push your vault as backup |

## Vault Path Recommendation

Keep this folder as a separate vault from your main notes so the structure stays clean.
