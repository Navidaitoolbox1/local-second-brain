# The Second Brain method

## Core Idea
A Second Brain is an external, trusted system for what you learn and create, so your mind is free to think instead of remember.

## The CODE workflow
- **Capture** — save what resonates, fast, in one Inbox.
- **Organize** — file by what it's *for* (project, area, resource).
- **Distill** — reduce each note to its essence.
- **Express** — turn notes into output.
